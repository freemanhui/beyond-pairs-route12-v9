# Scientific producer sources

These four files are exact source snapshots of the v11 scientific drivers and independent reviewer. Their original execution imports a private path/custody adapter and restricted saved laws and records, which are deliberately not bundled. They document the original rosters, seed construction, ordering, diagnostics and failure handling; they are not standalone commands. No private Git history or path adapter is included.

For runnable explicit-input code use `beyond_pairs.route12_benchmarks.portable`; its fitting/statistic core is byte-identical to the original core. The released `reproduce` command rebuilds the reported tables from scalar records without the biological model. The public demonstration uses a different artificial law and does not regenerate the MSK fits.
